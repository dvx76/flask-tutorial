FlaskR is a compact teaching app based on the official Flask tutorial. It is small enough to read in one sitting, but complete enough to demonstrate configuration, database access, authentication, CRUD flows, and test-driven development.[^tutorial]

!!! info "Why this project works well in class 🎓"
    It gives students a realistic web app without overwhelming them.

    - The application factory keeps setup in one place.
    - The `auth` and `blog` blueprints separate concerns clearly.
    - The SQLAlchemy ORM connects Python models to a real database.
    - The docs site mixes narrative pages with generated API reference.

## The app factory in one glance

```py title="flaskr/__init__.py"
def create_app(test_config=None):
    app = Flask(__name__)
    app.config.from_object("flaskr.settings")  # (1)!
    app.config.from_envvar("FLASKR_SETTINGS", silent=True)  # (2)!

    db_session, remove_session = db.create_db_session(  # (3)!
        app.config["DATABASE_URL"]
    )
    app.config["DB_SESSION"] = db_session

    app.teardown_appcontext(remove_session)  # (4)!
    app.register_blueprint(auth.bp)  # (5)!
    app.register_blueprint(blog.bp)  # (6)!

    return app
```

1. Load the default values from `flaskr/settings.py`.
2. Optionally override them with the `FLASKR_SETTINGS` environment variable.
3. Create the request-scoped database session.
4. Clean up the session at the end of each request.
5. Register authentication routes under `/auth`.
6. Register the main blog routes.
